WHY CLOUDMANAGER

轻量部署,安全可靠

为中小企业打造:不需要 K8s 集群和一堆中间件,一个可执行文件就能跑起来。

单二进制,零依赖

Go 编译的单文件程序,内置 SQLite 数据库,内嵌前端页面,解压即用,一条命令启动整个平台。

数据完全本地化

资源快照与密钥全部存在你自己的服务器上,不经任何第三方中转,内网环境同样可用。

一键全量同步

支持多地域并发拉取全部资源,也支持开启定时自动同步,快照永远保持新鲜。

权限与安全内建

JWT 登录鉴权、AES-GCM 密钥加密、全量操作日志,安全能力开箱自带,无需额外配置。

GET STARTED

三步开始使用

全程不超过 5 分钟,立即拥有属于你的多云管理台。

下载并运行

从发布包下载对应平台的可执行文件,直接运行,浏览器访问 http://localhost:8002。

./cloud-manager-windows-amd64.exe

录入云账号

在「云账号」页面录入阿里云 / 腾讯云 AccessKey(自动 AES 加密存储),点击同步拉取全部资源。

云账号 → 新建账号 → 一键同步

开始统一管理

仪表盘总览资产,跨云操作服务器,管理域名与 DNS 解析,还能开 WebShell 应急登录。

admin / admin123
