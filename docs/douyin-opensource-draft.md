## 图文分页
**P1 封面**:多云管理平台 / 我把它开源了 / 阿里云 + 腾讯云 一个后台搞定

**P2 痛点**:你是不是也这样?阿里云控制台登一遍,腾讯云控制台再登一遍;域名到期了才发现;解析记录散落在两个平台。切来切去,太折腾

**P3 我做了什么**:所以我自己写了一个。一个页面,管所有云。服务器 / 域名 / DNS 解析,阿里云 + 腾讯云 统一管理

**P4 功能亮点**(配截图):
- 仪表盘:资源、状态、云厂商分布一眼看清
- 云服务器:跨云统一列表,开机/关机/重启
- 域名管理:到期自动高亮提醒
- DNS 解析:A/AAAA/CNAME/MX/TXT 增删改查
- 操作日志:谁动了什么全留痕

**P5 安全**:AccessKey 密钥 AES 加密存储;数据全在你自己的服务器;不经过任何第三方。私有部署,数据自己掌握

**P6 部署简单**:Go 后端 + React 前端;纯 Go SQLite,不用装数据库;不需要 GCC;编译成一个文件,直接跑

**P7 技术栈**:Go (Gin) + SQLite;React + Ant Design 5;业务层只面向 CloudProvider 接口;想接华为云、AWS?加一个适配器就行

**P8 结尾**:近期正式开源,关注我,第一时间拿地址。评论区告诉我:你还想管哪家云?点赞最高的,我优先适配
